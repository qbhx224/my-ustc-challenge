# 循环链表

## 循环单链表

尾节点的 next 不指向 NULL，而是指向头结点。

```
        ┌──────────────────────────┐
        ↓                          │
[头结点] → [a₁] → [a₂] → [a₃] ──┘
```

### 判空条件

```c
L->next == L    // 头结点的 next 指向自己，就是空表
```

注意：不是 `L->next == NULL`！

### 判尾条件

```c
p->next == L    // 节点的 next 指向头结点，就是尾节点
```

### 特性

- 从任意节点出发都能遍历整个链表
- 不需要头指针，用尾指针更方便（尾->next 就是头）

### 尾指针的优势

如果用尾指针 R 而不是头指针：
- 访问第一个节点：`R->next->next`（头结点的下一个），O(1)
- 访问最后一个节点：`R` 本身，O(1)
- 两个循环链表合并：只需改两个指针，O(1)

```c
// 合并两个循环链表（尾指针 R1, R2）
p = R1->next;        // 保存 R1 的头结点
R1->next = R2->next->next;  // R1 的尾接 R2 的第一个数据节点
R2->next = p;        // R2 的尾接 R1 的头结点
free(R2->next);      // 释放 R2 的头结点（可选）
```

## 循环双链表

头结点的 prior 指向尾节点，尾节点的 next 指向头结点。

```
        ┌───────────────────────────────┐
        ↓                               │
[头结点] ⇄ [a₁] ⇄ [a₂] ⇄ [a₃] ←─────┘
        ↑                               │
        └───────────────────────────────┘
```

### 判空条件

```c
L->next == L && L->prior == L
// 或者只判一个也行：L->next == L
```

### 插入（在 p 之后插入 s）

```c
s->next = p->next;
p->next->prior = s;
s->prior = p;
p->next = s;
```

和双链表一样四步，但**不需要判空**！因为循环链表没有 NULL，p->next 一定有节点（至少是头结点）。

### 删除（删除节点 p）

```c
p->prior->next = p->next;
p->next->prior = p->prior;
free(p);
```

同样**不需要判空**，这是循环双链表比普通双链表好用的地方。

## 对比总结

| 类型 | 判空 | 有无 NULL | 删除是否要判空 |
|------|------|-----------|--------------|
| 单链表 | L->next == NULL | 有 | 不需要 |
| 循环单链表 | L->next == L | 无 | 不需要 |
| 双链表 | L->next == NULL | 有 | 删尾节点要判 |
| 循环双链表 | L->next == L | 无 | 不需要 |

## 考试重点

1. **判空条件**：循环链表不是判 NULL，而是判是否指向头结点
2. **循环双链表插入/删除不需要判空**（选择题常考）
3. **两个循环链表合并**的指针操作（代码题）
4. 尾指针表示的循环链表，首尾操作都是 O(1)
