# 时间复杂度与空间复杂度

## 时间复杂度

**定义**：代码执行次数随数据量 n 增长的量级，忽略系数和低次项。

```python
# O(1) — 常数时间
x = arr[0]

# O(n) — 线性时间
for i in arr:
    print(i)

# O(n²) — 平方时间
for i in arr:
    for j in arr:
        print(i, j)
```

**化简规则**：3n² + 5n + 100 → O(n²)，只留最高次项，去掉系数。

## 常见复杂度排序（从快到慢）

```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ)
```

## 典型代码模式

| 代码模式 | 复杂度 | 原因 |
|---------|--------|------|
| 直接取值 arr[i] | O(1) | 一步到位 |
| 遍历数组 | O(n) | n个元素走一遍 |
| 嵌套两层循环 | O(n²) | n × n |
| 每次砍一半（二分） | O(log n) | n→n/2→n/4→...→1，砍log n次 |

## log n 的直觉

n=8 时，log₂8 = 3（砍3次到1）。n 越大 log n 增长越慢，O(log n) 很快。

## 空间复杂度

**定义**：代码额外使用了多少内存。

```python
# O(1) 空间 — 只用几个变量
sum = 0
for i in arr:
    sum += i

# O(n) 空间 — 新建同样大小的数组
new_arr = []
for i in arr:
    new_arr.append(i * 2)
```

## 考试常见坑

1. **递归空间复杂度**：递归深度 = 空间复杂度，递归 n 层 → O(n)
2. **复杂度看最坏情况**：查找最坏 O(n)，不管最好是否 O(1)
3. **嵌套循环不一定是 O(n²)**：内层循环跟外层有关时要具体分析
