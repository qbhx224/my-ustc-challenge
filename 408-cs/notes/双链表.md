# 双链表

## 结构定义

```c
typedef struct DNode {
    int data;
    struct DNode *prior;  // 前驱指针
    struct DNode *next;   // 后继指针
} DNode, *DLinkList;
```

比单链表多了一个 `prior` 指针，可以**双向遍历**。

## 带头结点的双链表

```
NULL ← [头结点] ⇄ [a₁] ⇄ [a₂] ⇄ [a₃] → NULL
         ↑
        头指针L
```

- 头结点的 prior 指向 NULL
- 尾节点的 next 指向 NULL

## 基本操作

### 插入（在第 i 个位置插入）

在节点 p 之后插入节点 s：

```c
s->next = p->next;      // ① s的后继指向p的后继
p->next->prior = s;     // ② p的后继的前驱指向s（注意判空！）
s->prior = p;           // ③ s的前驱指向p
p->next = s;            // ④ p的后继指向s
```

**四步顺序**：先处理 s 的指针，再处理相邻节点的指针。

```
插入前：  p ⇄ [a]

步骤①③：  s 的 prior 和 next 先接好
         p ⇄ [a]
              ↑
             [s]（s指向了两边，但两边还没指向s）

步骤②④：  相邻节点指向 s
         p ⇄ s ⇄ [a]
```

**易错点**：步骤② `p->next->prior = s` 要在步骤④ `p->next = s` **之前**！否则 p->next 已经变成 s 了，就指向自己了。

### 删除（删除节点 p 的后继节点 q）

```c
q = p->next;            // q 是要删的节点
p->next = q->next;      // p 跳过 q
q->next->prior = p;     // q 的后继的前驱指向 p
free(q);
```

**只有两步改指针**，比插入简单。

**易错点**：删除尾节点时，q->next 是 NULL，`q->next->prior` 会空指针！要先判 q->next != NULL。

## 对比单链表

| 操作 | 单链表 | 双链表 |
|------|--------|--------|
| 插入 | 2步指针 | 4步指针 |
| 删除 | 2步指针 | 2步指针（但要判空） |
| 反向遍历 | 不支持 | 支持 |
| 空间 | 每节点1个指针 | 每节点2个指针 |

## 考试重点

1. **插入的四步顺序**（尤其是 ② 和 ④ 的先后）
2. **删除时的边界条件**（删尾节点要判空）
3. 给代码问执行后链表状态（画图推演）
