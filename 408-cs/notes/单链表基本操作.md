# 单链表基本操作

## 结构定义

```c
typedef struct LNode {
    int data;              // 数据域
    struct LNode *next;    // 指针域，指向下一个节点
} LNode, *LinkList;
```

- `LNode` 是节点类型
- `LinkList` 是指向节点的指针类型（即头指针的类型）

## 重要区分：头结点 vs 不带头结点

### 带头结点（推荐，考试默认）

```
头指针L → [头结点|next] → [a₁|next] → [a₂|next] → NULL
```

- 头结点的 data 无意义，next 指向第一个数据节点
- **好处**：空表和非空表统一处理，不用特判

### 不带头结点

```
头指针L → [a₁|next] → [a₂|next] → NULL
```

- L 直接指向第一个数据节点
- 空表时 L == NULL
- 插入/删除第一个节点时要特殊处理

## 带头结点的基本操作

### 1. 初始化 InitList(L)

```c
bool InitList(LinkList *L) {
    *L = (LNode *)malloc(sizeof(LNode));  // 分配头结点
    if (*L == NULL) return false;
    (*L)->next = NULL;                     // 头结点指针置空
    return true;
}
```
**要点**：头结点必须分配内存，next 置 NULL

### 2. 头插法建表（重要！）

每次新节点插在头结点之后，结果**逆序**。

```c
LinkList HeadInsert(LinkList L, int arr[], int n) {
    LNode *s;
    for (int i = 0; i < n; i++) {
        s = (LNode *)malloc(sizeof(LNode));
        s->data = arr[i];
        s->next = L->next;    // 新节点指向原第一个节点
        L->next = s;           // 头结点指向新节点
    }
    return L;
}
```

**过程演示**（插入 1, 2, 3）：

```
初始：  头结点 → NULL

插1：   头结点 → [1] → NULL

插2：   头结点 → [2] → [1] → NULL

插3：   头结点 → [3] → [2] → [1] → NULL
```

**结果是逆序的！** 输入 1,2,3，得到 3,2,1。

**记忆口诀**：头插逆序

### 3. 尾插法建表

每次新节点插在表尾，结果**顺序**。

```c
LinkList TailInsert(LinkList L, int arr[], int n) {
    LNode *s, *r = L;  // r 是尾指针，初始指向头结点
    for (int i = 0; i < n; i++) {
        s = (LNode *)malloc(sizeof(LNode));
        s->data = arr[i];
        r->next = s;    // 尾节点指向新节点
        r = s;           // 尾指针移到新节点
    }
    r->next = NULL;     // 最后一个节点指向 NULL
    return L;
}
```

**过程演示**（插入 1, 2, 3）：

```
初始：  头结点 → NULL        (r在头结点)

插1：   头结点 → [1] → NULL   (r移到1)

插2：   头结点 → [1] → [2] → NULL  (r移到2)

插3：   头结点 → [1] → [2] → [3] → NULL  (r移到3)
```

**结果是顺序的！**

**记忆口诀**：尾插顺序，别忘最后 r->next = NULL

### 4. 按位查找 GetElem(L, i)

返回第 i 个节点的指针。

```c
LNode *GetElem(LinkList L, int i) {
    if (i < 0) return NULL;
    LNode *p = L;          // p 从头结点开始
    int j = 0;             // 当前是第 0 个（头结点）
    while (p != NULL && j < i) {
        p = p->next;
        j++;
    }
    return p;              // 找到返回指针，没找到返回 NULL
}
```

**关键理解**：
- p 从头结点开始（j=0），不是从第一个数据节点开始
- 循环 i 次后，p 就指向第 i 个节点
- i=0 返回头结点，i=1 返回第一个数据节点

### 5. 按值查找 LocateElem(L, e)

```c
LNode *LocateElem(LinkList L, int e) {
    LNode *p = L->next;    // 从第一个数据节点开始
    while (p != NULL && p->data != e) {
        p = p->next;
    }
    return p;              // 找到返回指针，没找到返回 NULL
}
```

### 6. 插入 Insert(L, i, e)（重点！）

在第 i 个位置插入元素 e。

**方法：找到第 i-1 个节点，把新节点插在它后面。**

```c
bool Insert(LinkList L, int i, int e) {
    LNode *p = GetElem(L, i - 1);  // 找到第 i-1 个节点
    if (p == NULL) return false;     // 位置不合法
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;
    s->next = p->next;   // ① 新节点指向原第 i 个节点
    p->next = s;          // ② 第 i-1 个节点指向新节点
    return true;
}
```

**指针修改顺序不能换！** 必须先 ① 再 ②。

```
插入前：  p → [ai] → [ai+1]

步骤①：  s->next = p->next   (s指向ai)
         p → [ai] → [ai+1]
              ↑
             [s]

步骤②：  p->next = s         (p指向s)
         p → [s] → [ai] → [ai+1]
```

如果先 ② 再 ①：
```
p->next = s   →   p → [s]    [ai] → [ai+1]
s->next = p->next  →   s → [s]  （指向自己！原链断了！）
```

### 7. 删除 Delete(L, i, e)（重点！）

删除第 i 个节点，用 e 返回被删值。

**方法：找到第 i-1 个节点，让它跳过第 i 个节点。**

```c
bool Delete(LinkList L, int i, int *e) {
    LNode *p = GetElem(L, i - 1);  // 找到第 i-1 个节点
    if (p == NULL || p->next == NULL) return false;
    LNode *q = p->next;    // q 指向第 i 个节点（要删的）
    *e = q->data;           // 取出被删元素的值
    p->next = q->next;      // 第 i-1 个节点指向第 i+1 个
    free(q);                // 释放第 i 个节点的内存
    return true;
}
```

```
删除前：  p → [ai] → [ai+1]

p->next = q-next   →   p → [ai+1]    [ai]被跳过
free(q)               →   [ai] 被释放
```

## 对比顺序表

| 操作 | 顺序表 | 单链表 |
|------|--------|--------|
| 按位查找 | **O(1)** 直接算地址 | O(n) 要遍历 |
| 按值查找 | O(n) | O(n) |
| 插入 | O(n) 移动元素 | **O(1)** 改指针（已知前驱时） |
| 删除 | O(n) 移动元素 | **O(1)** 改指针（已知前驱时） |

**注意**：链表的插入/删除 O(1) 的前提是**已经拿到了前驱节点**。如果要先按位查找再操作，总复杂度还是 O(n)。
