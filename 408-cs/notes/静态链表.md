# 静态链表

## 是什么

用**数组**模拟链表。每个数组元素存数据 + "下一个元素的下标"（代替指针）。

适用场景：没有指针的语言（如早期 BASIC、FORTRAN），考试偶尔考。

## 结构定义

```c
#define MaxSize 100
typedef struct {
    int data;    // 数据
    int next;    // 下一个元素的数组下标（类似指针）
} SLinkList[MaxSize];
```

## 存储方式

```
下标：   0    1    2    3    4    5
data：  [空] [10] [30] [20] [空] [空]
next：  [2]  [3]  [0]  [-1] [空] [空]
         ↑                        ↑
        头结点（next=2）         空闲链头
```

- 下标 0 当头结点，next 指向第一个数据元素
- next = -1 表示链表结束（相当于 NULL）
- 空闲位置也串成一条链，方便分配和回收

## 操作特点

- 插入/删除：和链表一样改 "next" 值，不需要移动元素
- 查找：和链表一样从头遍历
- 没有真正的 malloc/free，用空闲链管理空间

低，了解即可。主要考：怎么用数组下标模拟指针操作。
