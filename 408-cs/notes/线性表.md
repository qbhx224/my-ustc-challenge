# 线性表

## 定义

线性表是具有**相同数据类型**的 n 个数据元素的**有限序列**。

```
L = (a₁, a₂, a₃, ..., aₙ)
```

- a₁ 是表头（第一个元素），没有前驱
- aₙ 是表尾（最后一个元素），没有后继
- 除首尾外，每个元素有且仅有一个前驱和一个后继

**关键词**：有限、有序、相同类型、序列

## 两种存储结构

### 顺序表（数组实现）

用一段**连续的内存空间**存储数据。

```
地址：  100  104  108  112  116
数据：  [10] [20] [30] [40] [50]
        a₁   a₂   a₃   a₄   a₅
```

**特点**：
- 随机访问：O(1)，直接用下标算地址 `LOC(aᵢ) = LOC(a₁) + (i-1) × sizeof(元素)`
- 插入/删除：O(n)，因为要移动后面的元素
- 空间：预分配，可能浪费

### 链表（指针实现）

每个节点存数据 + 指向下一个节点的指针。

```
[data|next] → [data|next] → [data|next] → NULL
  a₁           a₂           a₃
```

**特点**：
- 随机访问：O(n)，要从头遍历
- 插入/删除：O(1)（已知节点位置时），只需改指针
- 空间：动态分配，不浪费

## 基本操作对比

| 操作 | 顺序表 | 链表 |
|------|--------|------|
| 按位查找 GetElem(L, i) | O(1) | O(n) |
| 按值查找 LocateElem(L, e) | O(n) | O(n) |
| 插入 Insert(L, i, e) | O(n) | O(1)* |
| 删除 Delete(L, i) | O(n) | O(1)* |
| 头插法建表 | — | O(n) |
| 尾插法建表 | — | O(n) |

*前提是已经定位到插入/删除位置的节点

## 链表的分类

| 类型 | 特点 |
|------|------|
| 单链表 | 每个节点一个指针，指向后继 |
| 双链表 | 两个指针，指向前驱和后继 |
| 循环单链表 | 尾节点指回头节点 |
| 循环双链表 | 尾指回头，头指回尾 |
| 静态链表 | 用数组模拟链表（无指针语言用） |

## 头结点 vs 头指针

- **头指针**：指向链表第一个节点的指针（链表的标识）
- **头结点**：在第一个数据节点之前附加的节点，数据域无意义
  - 好处：统一空表和非空表的操作，不用特殊处理第一个节点

```
头指针 → [头结点] → [a₁] → [a₂] → NULL
```

## 考试高频考点

1. 顺序表和链表的**操作复杂度对比**（选择题常考）
2. 链表的**头插法和尾插法**建表（代码题常考）
3. 双链表插入/删除的**指针修改顺序**（顺序错了会断链）
4. 循环链表的**判空条件**（不是 == NULL，而是 == 头结点）
