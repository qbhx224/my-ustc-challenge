# 顺序表基本操作

## 结构定义

```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];  // 静态分配数组
    int length;          // 当前长度
} SqList;
```

动态分配版本：
```c
#define InitSize 100
typedef struct {
    int *data;          // 指向动态分配数组的指针
    int MaxSize;        // 最大容量
    int length;         // 当前长度
} SeqList;
```

## 核心操作

### 1. 初始化 InitList(L)

```c
void InitList(SqList *L) {
    L->length = 0;  // 长度置零，其他不用管
}
```
**时间复杂度**：O(1)

### 2. 插入 Insert(L, i, e)

在第 i 个位置插入元素 e（i 从 1 开始）。

```c
bool Insert(SqList *L, int i, int e) {
    if (i < 1 || i > L->length + 1)  // 位置合法性
        return false;
    if (L->length >= MaxSize)          // 表满
        return false;
    for (int j = L->length; j >= i; j--)  // 从后往前移
        L->data[j] = L->data[j-1];
    L->data[i-1] = e;                 // 插入（注意下标是i-1）
    L->length++;
    return true;
}
```

**关键点**：
- 从后往前移动，防止覆盖
- 下标 = 位置 - 1（第i个元素对应 data[i-1]）
- **时间复杂度**：
  - 最好 O(1)：插在最后，不用移动
  - 最坏 O(n)：插在最前，移动 n 个
  - 平均 O(n)：平均移动 n/2 个

### 3. 删除 Delete(L, i, e)

删除第 i 个位置的元素，用 e 返回被删值。

```c
bool Delete(SqList *L, int i, int *e) {
    if (i < 1 || i > L->length)       // 位置合法性
        return false;
    *e = L->data[i-1];                 // 先取出被删元素
    for (int j = i; j < L->length; j++)  // 从前往后移
        L->data[j-1] = L->data[j];
    L->length--;
    return true;
}
```

**关键点**：
- 从前往后移动（和插入相反）
- **时间复杂度**：平均 O(n)

### 4. 按位查找 GetElem(L, i)

```c
int GetElem(SqList L, int i) {
    return L.data[i-1];  // 直接用下标，O(1)
}
```
**时间复杂度**：O(1) — 顺序表的最大优势

### 5. 按值查找 LocateElem(L, e)

```c
int LocateElem(SqList L, int e) {
    for (int i = 0; i < L.length; i++) {
        if (L.data[i] == e)
            return i + 1;  // 返回位置（从1开始）
    }
    return 0;  // 没找到
}
```
**时间复杂度**：平均 O(n)

## 易错点

1. **i 从 1 开始，下标从 0 开始**：第 i 个元素是 data[i-1]
2. **插入要从后往前移**：从前往后会覆盖数据
3. **删除要从前往后移**：和插入方向相反
4. **判满条件**：length >= MaxSize，不是 > MaxSize
5. **插入位置范围**：1 ≤ i ≤ length+1（可以插在最后）
6. **删除位置范围**：1 ≤ i ≤ length（不能删空位）

## 复杂度速记

| 操作 | 最好 | 最坏 | 平均 |
|------|------|------|------|
| 插入 | O(1) | O(n) | O(n) |
| 删除 | O(1) | O(n) | O(n) |
| 按位查找 | O(1) | O(1) | O(1) |
| 按值查找 | O(1) | O(n) | O(n) |
