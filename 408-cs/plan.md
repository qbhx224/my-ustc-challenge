# 408 计算机学科专业基础综合 · 学习计划

## 科目概况
- 分值：150分
- 组成：数据结构 45分 + 计算机组成原理 45分 + 操作系统 35分 + 计算机网络 25分
- 当前水平：接近零基础，需要从头系统学习

## 学习顺序
数据结构 → 计算机组成原理 → 操作系统 → 计算机网络

> 数据结构是其他三门的基础，务必第一个学、学扎实。

## 阶段规划

### 第一阶段：数据结构基础（2026.7 - 2026.10）
- [ ] 线性表（顺序表、链表、双向链表、循环链表）
- [ ] 栈和队列（定义、实现、应用：括号匹配、表达式求值）
- [ ] 树与二叉树（遍历、线索二叉树、哈夫曼树、B树）
- [ ] 图（存储、DFS/BFS、最短路径、最小生成树、拓扑排序）
- [ ] 查找（顺序、折半、B树、哈希）
- [ ] 排序（快排、归并、堆排、希尔、基数 — 手写代码级掌握）

> 目标：能手写每种数据结构的核心操作，理解时间/空间复杂度

### 第二阶段：计组基础（2026.10 - 2027.1）
- [ ] 数据表示（进制、浮点数、补码运算）
- [ ] 运算器（加减乘除、ALU）
- [ ] 存储系统（Cache、虚存、局部性原理）
- [ ] 指令系统（寻址方式、CISC vs RISC）
- [ ] CPU（数据通路、流水线、中断）
- [ ] 总线与I/O

### 第三阶段：操作系统 + 计网（2027.1 - 2027.4）
- [ ] OS：进程管理（调度、同步、死锁）
- [ ] OS：内存管理（分页、分段、虚拟内存）
- [ ] OS：文件管理与I/O
- [ ] 计网：物理层、数据链路层
- [ ] 计网：网络层（IP、路由算法）
- [ ] 计网：传输层（TCP三次握手、拥塞控制、UDP）
- [ ] 计网：应用层（HTTP、DNS、SMTP）

### 第四阶段：全面强化（2027.4 - 2027.8）
- [ ] 王道四本单科书课后题全刷
- [ ] 重点章节二刷（数据结构的图和排序、计组的CPU和存储、OS的进程、计网的TCP）
- [ ] 建立错题本

### 第五阶段：真题 + 冲刺（2027.8 - 2027.12）
- [ ] 近15年408真题按年份模拟
- [ ] 错题分类回顾
- [ ] 模拟卷（王道模拟题）
- [ ] 考前公式/协议/知识点速记
