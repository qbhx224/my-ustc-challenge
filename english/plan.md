# 204 英语二 · 学习计划

## 科目概况
- 分值：100分
- 题型：完形 10分 + 阅读 40分 + 新题型 10分 + 翻译 15分 + 写作 25分
- 当前水平：有基本读写能力，词汇量不足，翻译精确度和写作深度需提升

## 核心策略
词汇是地基，阅读是大头。每天背单词贯穿全程，前期主攻词汇+长难句，后期主攻阅读+写作。

## 阶段规划

### 第一阶段：词汇 + 长难句（2026.7 - 2026.10）
- [ ] 考研词汇过第1遍（每天50-80个新词 + 复习）
- [ ] 考研词汇过第2遍（重点标记生词）
- [ ] 长难句基础（会拆主谓宾、识别从句类型）
- [ ] 每天1篇早期真题阅读精读（2005-2009）

> 背单词方法：用墨墨背单词/不背单词APP，每天固定30-40分钟，利用碎片时间复习

### 第二阶段：阅读主攻（2026.10 - 2027.4）
- [ ] 阅读真题精练（2010-2019），每篇做到：
  - 生词全部标注
  - 长难句逐句翻译
  - 每题分析为什么选/不选
- [ ] 唐迟阅读方法论（学解题思路）
- [ ] 每天背单词持续

### 第三阶段：全面展开（2027.4 - 2027.8）
- [ ] 阅读真题（2020-2023）
- [ ] 翻译专项（英译汉，练精确度）
- [ ] 完形填空技巧（红花绿叶词、逻辑关系）
- [ ] 新题型（排序、小标题、信息匹配）
- [ ] 作文：积累句型和素材

### 第四阶段：写作 + 模拟（2027.8 - 2027.12）
- [ ] 大作文模板整理（图表描述+分析+总结）
- [ ] 小作文模板整理（书信、通知等）
- [ ] 每周写1篇作文并批改
- [ ] 近3年真题完整模拟（限时3小时）
- [ ] 考前背诵作文范文10篇

## 备考资料
- 单词：墨墨背单词APP + 红宝书（查漏）
- 作文：王江涛高分写作
- 真题：张剑黄皮书（解析详细）
