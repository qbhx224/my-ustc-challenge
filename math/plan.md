# 302 数学二 · 学习计划

## 科目概况
- 分值：150分
- 范围：高等数学 + 线性代数（不含概率论）
- 题型：选择 50分 + 填空 30分 + 解答题 70分
- 当前水平：基本求导/积分/矩阵运算OK，概念理解浅，线代理论需从零学

## 学习顺序
高数上 → 高数下 → 线性代数

## 阶段规划

### 第一阶段：高数基础（2026.7 - 2026.10）
- [ ] 极限（定义、性质、两个重要极限、等价无穷小）
- [ ] 导数与微分（求导法则、隐函数求导、参数方程求导）
- [ ] 中值定理（罗尔、拉格朗日、柯西 — 证明题高频考点）
- [ ] 不定积分（换元、分部、有理函数）
- [ ] 定积分及应用（面积、体积、弧长）
- [ ] 微分方程（一阶、二阶常系数线性）
- [ ] 多元函数微分（偏导、全微分、极值、条件极值）
- [ ] 二重积分

> 每章看完视频后，用660题对应章节检验

### 第二阶段：线代基础（2026.10 - 2026.12）
- [ ] 行列式（计算方法、性质）
- [ ] 矩阵（逆矩阵、秩、初等变换）
- [ ] 向量（线性相关、极大无关组、秩）
- [ ] 线性方程组（齐次/非齐次、解的结构）
- [ ] 特征值与特征向量（定义、求法、对角化）
- [ ] 二次型（标准形、正定性）

> 线代重理解，不能只会算。每学一个概念，问自己"几何意义是什么""为什么这么定义"

### 第三阶段：强化刷题（2027.1 - 2027.5）
- [ ] 660题全刷 + 错题整理
- [ ] 高数中值定理专题
- [ ] 高数级数专题（数项级数、幂级数展开）
- [ ] 线代综合题
- [ ] 880题（选做）

### 第四阶段：真题（2027.5 - 2027.9）
- [ ] 近20年真题按年份模拟（限时3小时）
- [ ] 错题归类（计算失误 vs 概念不清 vs 方法不会）
- [ ] 薄弱章节针对性补强

### 第五阶段：冲刺（2027.9 - 2027.12）
- [ ] 模拟卷（李林6+4 / 张宇8+4）
- [ ] 公式定理手册过2遍
- [ ] 计算能力每天练（极限、积分、矩阵运算各5题）
- [ ] 考前2周只看错题和公式

## 备考资料
- 教材：同济高数 + 同济线代
- 习题：660题（必刷）→ 880题（选做）→ 330题（选做）

- 模拟：李林6+4 / 张宇8+4
